## 확인한 항목

- JavaScript 구문 검사: `node --check public/app.js` 통과.
- HTML의 로컬 파일 참조와 중복 ID 검사 통과.
- Chromium 화면 너비 320px·390px·768px·1440px에서 가로 넘침, 잘린 제목, 이미지 로딩 실패 없음.
- 모바일 메뉴 열기, Escape 닫기, 메뉴 링크 이동과 자동 닫기 확인.
- FAQ 열기 확인.
- 전화번호 복사 성공 안내 확인. 브라우저의 복사 차단을 재현했을 때 수동 복사 입력란 표시·포커스·번호 전체 선택 확인.
- 동작 줄이기 설정에서 비눗방울 애니메이션 해제 확인.
- JavaScript 비활성화 상태에서 모바일 메뉴와 FAQ를 열 수 있고 전화 링크가 존재하며, 복사 버튼은 숨겨짐.
- 전화·문자 링크의 대상은 모두 `01066987572`다. 실제 발신·전송은 하지 않음.
- 가격표와 문의 수집 양식이 없고, 삭제 요청된 ‘깨끗함을 차곡차곡’ 문구가 없음.
- 독립적인 소스 리뷰에서 중요 결함이 발견되지 않음.
- 브라우저의 테스트용 HTTP 응답에 `public/_headers`의 CSP를 적용했을 때 스크립트·스타일·이미지가 로드되고 오류 메시지가 발생하지 않음.

## 검증 경계

- 로컬 Python 서버는 `_headers`를 실제로 적용하지 않는다. CSP 확인은 브라우저 테스트의 응답에 정책을 넣어 재현한 결과다.
- 초기 로컬 검증 후 아래 기록과 같이 GitHub Pages 공개 배포를 완료했다. 사용자 지정 도메인 연결과 검색 등록은 하지 않았다.
- 실제 iPhone·Android 기기와 Safari에서의 발신·문자 앱 연결은 확인하지 않았다.
- 캐릭터는 전단지 기반 편집본이다. 회사 소개·실제 작업 사진·로고 원본은 추후 받은 자료로 보완한다.
- 초기 로컬 검증 후 GitHub 저장소를 만들고 소스 및 배포 워크플로를 커밋·푸시했다.

## 넓은 화면 너비 보완

- 1920px 화면에서도 본문이 1180px로 제한되어 좌우 여백이 커지는 현상을 재현했다.
- 본문의 고정 최대 너비와 캐릭터 영역의 별도 너비 제한을 제거했다. 화면 너비에 비례한 여백을 적용하고, 큰 화면의 제목 크기와 캐릭터 높이를 조정했다.
- 320px·390px·768px·1440px·1920px·2560px에서 가로 넘침과 잘린 제목이 없음을 확인했다.
- 1920px 브라우저에서 본문 너비가 약 1751px, 한쪽 여백이 약 77px로 변경됨을 확인했다. 스크롤바 너비가 포함된 측정값이다.
- 스타일시트 URL에 버전을 붙여 이전 스타일이 브라우저 캐시에 남는 현상을 방지했다.
