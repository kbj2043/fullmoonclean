# 보름달 크린 사이트 구현 계획

목표: 승인한 세 번째 시안을 실제 정적 웹사이트로 정리한다.

## 기준

- 프로젝트명은 `fullmoonclean`, 표시되는 회사명은 `보름달 크린`이다.
- 승인한 화면은 `design/index.html`이며, 좌측 상단 보조 문구를 다시 넣지 않는다.
- 김포 구래동·마산동·양촌 지역의 빌라·상가 계단 청소만 소개한다.
- 정기 청소는 주 1회, 월 4회다.
- 가격표·자동 견적·문의 수집 양식은 두지 않는다.
- 상담은 `010-6698-7572` 전화·문자로 연결하고, 현장 방문 후 조건을 협의한다.
- 로고는 전단지의 심벌을 사용한다. 캐릭터는 전단지 기반 편집본을 사용하며 추후 원본으로 교체한다.
- 확인되지 않은 경력·후기·작업 사진·보장 내용을 만들지 않는다.
- 외부 서비스, 계정, 분석 도구와 공개 배포는 이번 로컬 구현에서 연결하지 않는다.

- [x] `public/index.html`, `styles.css`, `app.js`로 화면과 상호작용을 분리한다.
- [x] 모바일 메뉴, 전화번호 복사, 확정된 정보로 구성한 FAQ를 구현한다.
- [x] 기본 검색 메타 정보, 이미지 크기, 접근성, 정적 배포 헤더를 정리한다.
- [x] 320px·390px·768px·1440px 화면, 메뉴·FAQ·복사 성공/실패, 동작 줄이기 설정, 연락처와 파일 경로를 검증한다.
- [x] 실행·배포·자료 교체 방법과 확인 결과를 기록한다.

## 구조

- `public/`: 실제 서비스에 올리는 정적 파일만 보관한다.
- `design/`: 승인한 시안, 원본 전단지, 캐릭터 편집 지시문, 비교 스크린샷을 보존한다.
- `docs/`: 구현 계획과 검증 결과를 남긴다.

## 결정 사항

- 서버 접수·회원가입·결제가 필요하지 않아 프레임워크나 빌드 의존성 없이 HTML·CSS·JavaScript를 사용한다.
- 옵시디언 볼트와 독립된 Git 저장소로 만든다. 요청 없이 커밋·푸시·공개 배포하지 않는다.
- 전화·문자 앱의 실제 발신은 하지 않고 링크의 대상 번호와 화면 동작을 확인한다.
